# Daily Card

بطاقتان يوميتان قابلتان للتحديث والنشر عبر GitHub Pages\.

## النشر على GitHub Pages

1. أنشئ مستودعًا جديدًا باسم `daily-card`\.
2. ارفع ملف `index.html` إلى جذر المستودع\.
3. افتح:
   Settings → Pages
4. اختر:
   Deploy from a branch
5. اختر:
   Branch: `main`
   Folder: `/ (root)`
6. اضغط Save\.

سيصبح الرابط:

https://mmasmoum\.github\.io/daily\-card/

## ملاحظات

- التطبيق يفتح على تاريخ اليوم تلقائيًا\.
- تغيير التاريخ يحدّث اسم اليوم والتاريخ الهجري والميلادي\.
- المواقيت تُجلب تلقائيًا عند توفر الإنترنت\.
- يمكن تعديل المواقيت يدويًا قبل التصدير\.
